Careers in Data & Tech

Data Analyst

A Data Analyst collects, cleans, and interprets data using tools like Excel, SQL, and Tableau.

If you like: Analyzing data, creating dashboards, working with spreadsheets.

Credentials:
  • IBM Data Analyst
  • Google Data Analytics
  • Excel to MySQL
  • + 2 more

Data Scientist

Analyzes large datasets to uncover insights, using statistics, machine learning, and visualization.

If you like: Building ML models, solving statistical problems, data-driven decisions.

Credentials:
  • IBM Data Science
  • DeepLearning.AI TensorFlow
  • Applied Data Science

Machine Learning Engineer

Builds and optimizes ML algorithms to enable computers to learn from data.

If you like: Neural networks, big data, Python or R, automation.

Credentials:
  • Machine Learning by Stanford
  • MathWorks Computer Vision
  • Advanced AI Engineering

Data Warehouse Developer

Designs and optimizes data warehouses, ensures efficient ETL workflows.

If you like: Managing large datasets, ETL, ensuring fast queries.

Credentials:
  • IBM Data Warehouse Engineer
  • BI with SQL & ETL
  • Data Warehousing on GCP
